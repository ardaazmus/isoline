# ISOLINE ERP dönüşümü

Isoline'ı tarayıcıda çalışan araç setinden çok kiracılı, PostgreSQL tabanlı bir raporlama operasyon platformuna taşıyan çalışma.

- **Plan:** [plan/](plan/README.md). Ürün sahibinin 19.10.2026 tarihli geliştirme sözleşmesi; değiştirilmeden saklanır.
- **Durum:** [DURUM.md](DURUM.md). Her görev kimliğinin durumu ve kanıtı.
- **Kararlar:** [adr/](adr/)
  - 001: barındırma
  - 002: kiracı ve dış erişim
  - 003: veri katmanı
  - 004: kimlik
  - 005: kanıt deposu
  - 006: kuyruk ve denetim izi
  - 007: API ve yetki
  - 008: v1 ile birlikte yaşam
  - 009: hesap ve soy ağacı
  - 010: kural sicili
  - 011: arayüz kabuğu
- **G0 çıktıları:** [G0/](G0/)
  - kod envanteri;
  - ekran haritası;
  - göç riski;
  - kabul senaryoları;
  - tehdit modeli.
- **Kurulum:** [../SERVER_KURULUM.md](../SERVER_KURULUM.md). G1 ile güncellenir.
